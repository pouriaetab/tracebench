# Scope and disclaimer

tracebench is an engineering and research project about verification, validation,
data pipelines and statistical evaluation. Market data is used only as a test bed:
a high volume, real time data source whose outcomes can be observed, which is what
validation needs.

1. **Not financial advice.** Nothing in this repository is investment, trading or
   financial advice, or a recommendation to buy, sell or hold anything. The author
   is not a financial adviser and does not act as one.
2. **No trading.** The code places no orders, connects to no brokerage account, and
   contains no strategy. Its models estimate statistical quantities (touch
   probabilities, rates, tail shapes) so that the V&V process around them can be
   demonstrated.
3. **No performance claims.** The numbers reported here describe calibration, error
   rates and data volumes. They are not, and must not be read as, returns or
   evidence that any use of the models would be profitable.
4. **No liability.** The software and documentation are provided "as is", without
   warranty of any kind (see [LICENSE](LICENSE)). The author accepts no liability for
   any loss or damage, financial or otherwise, arising from any use of this
   repository or of anything derived from it. Anyone who uses it does so entirely
   at their own risk.
5. **Data.** Raw market data is not distributed here. Only aggregate statistics are
   reported.
